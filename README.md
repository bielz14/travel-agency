# Travel Agency - Laravel 12 Project

**Дипломний проект:** Сайт туристичного агентства з повною функціональністю на Laravel 12.

---

## 📌 Опис проекту

Проект являє собою веб-застосунок для туристичного агентства, що включає:

- Каталог турів з пошуком по країні, місту, ціні та даті
- Перегляд детального опису туру, включаючи місто та готель
- Можливість бронювання туру через форму
- Залишення відгуків на тури
- Адмінка (CRUD) для всіх сутностей через Filament
- Повна структура БД рівня диплому
- Docker-середовище для швидкого запуску на будь-якій машині

Технології:

- PHP 8.2, Laravel 12
- MySQL 8
- Nginx
- Docker / Docker Compose
- Blade templates
- Filament Admin Panel

## 🚀 Швидкий запуск проекту на ПК, на якому він ще не запускався раніше

Виконайте наступні команди в терміналі **з кореня проекту**:
```bash
# 1. Збірка Docker-образів
docker-compose build

# 2. Запуск контейнерів у фоні
docker-compose up -d
```
